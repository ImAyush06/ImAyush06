## Featured Engineering Projects

### 1. Hospital Management System
- **Repository**: [github.com/ImAyush06/HospitalManagementSystem](https://github.com/ImAyush06/HospitalManagementSystem)
- **Tech Stack**: Java, Spring Boot, MongoDB, JavaScript, HTML5, CSS3
- Developed a comprehensive web-based platform to manage patient records and hospital operations, improving data organization.
- Implemented patient management, doctor scheduling, and administrative services with custom Min-Heap priority queues for emergency appointment handling.
- Engineered a modular RESTful backend in Spring Boot with MongoDB for persistent, reliable data management.

### 2. Smart Expression Evaluator
- **Repository**: [github.com/ImAyush06/Smart-Expression-Evaluator](https://github.com/ImAyush06/Smart-Expression-Evaluator)
- **Tech Stack**: C++17, WebAssembly (WASM), JavaScript, CSS3
- High-performance calculation engine engineered in C++17 and compiled to WebAssembly for execution in modern web browsers.
- Features custom Shunting-Yard expression parsing, infix-to-postfix syntax conversion, and an interactive dashboard.

### 3. Samriddhi Enterprises (Revenue Platform)
- **Repository**: [github.com/ImAyush06/revenue-frontend-project](https://github.com/ImAyush06/revenue-frontend-project)
- **Tech Stack**: React.js, JavaScript, HTML5, CSS3, Netlify
- Built a responsive commercial services platform to showcase business offerings, operational workflows, and enterprise resources.
- Implemented dedicated modules for PAN Card, GST verification, location verification, and transaction documentation.
- Deployed on Netlify with complete cross-device responsiveness.

### 4. Secure Authentication Module for Operating Systems
- **Repository**: [github.com/ImAyush06/Secure-Authentication-Module-for-Operating-Systems](https://github.com/ImAyush06/Secure-Authentication-Module-for-Operating-Systems)
- **Tech Stack**: C, TeX, Linux Security Architecture
- Operating system authentication architecture implementing salted cryptographic hashing, event auditing, and runtime intrusion monitoring.
- Features simulated defenses and vulnerability analysis against backdoor access, buffer overflow exploits, and brute-force attacks.

### 5. QuoteBot - AI-Powered Motivation Assistant
- **Repository**: [github.com/ImAyush06/Quote-Bot](https://github.com/ImAyush06/Quote-Bot)
- **Tech Stack**: Python, Flask, Google Gemini API, JavaScript, HTML5, CSS3
- Developed an AI-driven web application generating context-aware quotes using Google Gemini API.
- Implemented a secure Python Flask backend to handle API communications, credential protection, and structured responses.
- Client-side interface includes chat history tracking, local favorites caching, theme toggles, and clipboard integration.
